# Resolução CNJ 363/2021

## Ementa
Institui diretrizes para adequação dos tribunais às exigências da Lei Geral de Proteção de Dados (LGPD).

## Dispositivos Relevantes

| Artigo | Conteúdo |
|--------|----------|
| 1º | Objeto da resolução - adequação dos tribunais |
| 2º | Princípios da privacidade |
| 3º | Política de privacidade |
| 4º | Nomeação do Encarregado |
| 5º | Treinamento de servidores |
| 6º | Relatórios de privacidade |
| 7º | Comunicação de incidentes |
| 11º | Tratamento de dados sensíveis |

## 13 Medidas Obrigatórias

1. **Desenvolver política de privacidade**
2. **Garantir transparência no tratamento**
3. **Criar canal de comunicação**
4. **Nomear Encarregado pela Proteção de Dados**
5. **Realizar treinamento periódico**
6. **Implementar medidas de segurança**
7. **Garantir acesso aos dados**
8. **Realizar monitoramento de acesso**
9. **Proteger dados sensíveis**
10. **Controlar compartilhamento**
11. **Criar relatórios de privacidade**
12. **Comunicar incidentes**
13. **Garantir direitos dos titulares**
