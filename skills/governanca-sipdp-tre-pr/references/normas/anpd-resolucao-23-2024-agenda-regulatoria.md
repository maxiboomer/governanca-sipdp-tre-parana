# Resolução CD/ANPD nº 23/2024 — Agenda Regulatória 2025-2026

Aprova a Agenda Regulatória para o biênio 2025-2026.

## Contexto

A Agenda Regulatória da ANPD define as prioridades regulatórias para o biênio, organizadas em temas prioritários. É um instrumento de planejamento (não cria obrigações diretas).

- **Resolução CD/ANPD nº 31, de 22/12/2025** — altera a Agenda Regulatória 2025-2026
